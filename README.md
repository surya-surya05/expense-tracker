# Expense Tracker

A desktop expense tracking application developed using Python, SQLite,
Tkinter, and Object-Oriented Programming.

## Features

- Add expenses
- Update expenses
- Delete expenses
- View all expenses
- Categorize expenses
- Calculate total expenses
- SQLite database
- Input validation
- GUI using Tkinter

## Technologies

- Python
- SQLite
- Tkinter
- Object-Oriented Programming

## How to Run

### 1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Open the project

cd expense-tracker

### 3. Run the application

python app.py

The SQLite database will automatically be created inside
the data directory.
